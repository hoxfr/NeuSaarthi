# NeoSaarthi UI/UX Design System
**Author:** Ashna | **Date:** Sep 4, 2026 | **Version:** 1.0

## Design Philosophy
Elderly-first, dignity-centred design. Every interaction must be forgiving, legible, and calm.

## Accessibility Standards
| Rule | Requirement | Status |
|------|-------------|--------|
| Touch Target Size | Minimum 52×52px | ✅ |
| Body Font Size | Minimum 20px | ✅ |
| Color Contrast | WCAG AAA (≥7:1) | ✅ |
| Animation Speed | ≤300ms transitions | ✅ |
| Focus Indicator | 3px solid accent | ✅ |

## Color Palette
| Token | Hex | Use |
|-------|-----|-----|
| `--primary` | `#1565C0` | Buttons, active states |
| `--accent` | `#E65100` | Focus rings, alerts |
| `--text-primary` | `#1A1A1A` | Body text (10.3:1 ratio) |
| `--success` | `#2E7D32` | Positive feedback |

## Screen Inventory
1. **Home Screen** — Wellness score card, quick-access game/routine/family cards
2. **Game Menu** — AI-prioritized game list with difficulty badges
3. **Gauntlet Screen** — Active game session with progress ring
4. **Routine Screen** — Daily schedule, hydration tracker, audio therapy
5. **Family Screen** — Photo therapy quiz with face portraits
6. **Progress Screen** — Domain wellness rings, trend chart, AI baseline comparison
7. **Profile Screen** — User setup, SOS contacts, caregiver info
