# SIH Module 2: The "Gauntlet" Dynamic Cognitive Assessment Engine
**Assigned Role:** Core Algorithm & Clinical Logic Lead  
**Files Owned:** `js/gauntlet.js`

### What You Built (For SIH Jury Viva):
- 5-minute dynamic baseline cognitive assessment engine with 3 difficulty tiers.
- Adaptive difficulty scaling: Questions dynamically step up or down based on patient accuracy.
- Multi-domain evaluation matrix scoring: Memory, Executive Function, Language, and Orientation.
- 10-Disorder dementia risk classifier mapping clinical subtypes for caregiver setup.
